## 🔧 Setup Walkthrough

### Step 1 — Install Java 21
Download **Adoptium Temurin JDK 21** for your OS. ATM10 requires Java 21.

### Step 2 — Install CurseForge
Download the **CurseForge App** and log in with your account.

### Step 3 — Browse All The Mods
Search for **All The Mods 10** or **All The Mods 9** and click Install.

### Step 4 — Allocate RAM
Open CurseForge settings and set memory to **8 GB minimum**, 12 GB recommended.

### Step 5 — Add JVM Flags
Paste the tuned JVM flags from `JVM-Flags.txt` in the launcher.

### Step 6 — Launch & Play
Start the pack. First launch takes longer as mods are decompressed.
